# Product Overview

文房具を売る EC サイト。個人のお客様が商品を買うほかに、店が開く講座の予約、法人のお客様の購買申請と承認、法人向けの文房具の定期便（月額課金）を扱う。
AI 駆動開発研修の演習で使うサンプルアプリで、受講者は spec と実装を読み比べて欠陥を見つけ、AI に直させる。

## Core Capabilities

- EC: 商品の一覧・カート・購入の確定。購入を確定すると売上を記録する
- 講座の予約: 単発と連続の講座の席を予約し、規定に従ってキャンセル料を求める
- 購買申請と承認: 法人の担当者が購買を申請し、決裁権限の表に従って承認し、購買部が発注する
- 定期便の月額課金: プランの日割り・割引・消費税を決まった順に計算して、月ごとの請求書を作る

## Target Use Cases

- お客様が商品をカートに入れて購入する
- お客様が講座を予約し、必要ならキャンセルする
- 法人の社員が購買を申請し、上長が承認または差し戻し、購買部が発注する
- 店の担当者が定期便の請求書を月ごとに作る

## Value Proposition

4 つの業務は、欠陥の系統が違う（データの整合・境界と競合・状態の遷移と権限・計算の順序と端数）。
同じ土台（スタック・画面の枠・ログインと顧客）の上に業務ごとの機能を足してあり、検証のやり方を業務を替えて繰り返し使える。
