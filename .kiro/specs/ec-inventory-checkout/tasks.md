## Implementation Notes

- テストは `./mvnw test -f backend/pom.xml`（環境変数 SPRING_DATASOURCE_URL がこの worktree のテスト DB を指す）。出力が多いので backend/target/surefire-reports/*.txt で結果を見る
- 購入確定の売上の日時は Clock の Bean ではなく既存の `OffsetDateTime.now(TOKYO)` を引き継いでいる（design は既存の `now` を維持）。テストは前後の時刻の範囲で確かめる
- 購入確定: 要求に同じ商品 ID が複数あるときは小さい方の購入可能数を採る。売上と応答は商品 ID の昇順になる。availabilities に null の要素があると 500 になる（対象外）
- 画面（CartPage）は 7.3 まで availabilities を送らないため、それまでは購入確定が E02 になる
- 8.2: バックエンドの全テスト 117 件（失敗 0）と frontend の `npm run build` は成功を確認済み。画面の手動確認（design の確認項目）は、専用 DB の作成が権限で拒否されたため未実施。実施後に 8.2 を完了にする
